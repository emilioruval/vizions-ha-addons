# Complementos de Vizions para Home Assistant

Repositorio de complementos de [Vizions Networks](https://vizionsnetworks.com) para Home Assistant OS.

## Vizions Smart Living

Conecta la domótica de la casa con Vizions OS: el huésped la controla desde la TV y desde su
celular durante su estancia, y el dueño tiene el **Vizions Panel** en una tablet de pared.
La conexión con Vizions es **saliente**: no hay que abrir puertos en el router.

### Instalar

1. En Home Assistant: **Ajustes → Complementos → Tienda de complementos → ⋮ → Repositorios**.
2. Agrega `https://github.com/emilioruval/vizions-ha-addons` y cierra.
3. Busca **Vizions Smart Living** en la tienda → **Instalar**.
4. Llena las **Opciones** con los datos que te da Vizions y toca **Iniciar**.

Las instrucciones completas están en la pestaña **Documentación** del complemento.
Las versiones nuevas aparecen solas como **Actualizar**.

Este repositorio lo arma `scripts/addon-publicar.mjs` desde el repositorio privado de
Vizions Smart Living: no se edita a mano.
